2. 로그인 회원으로 찾을 수 없는 플레이어 UUID가 회원 연결을 기다리고 있었다. `REMOTE_ALLOW_GUESTS=1`일 때만 게스트를 생성한다. 실제 회원과 명시적 매핑을 우선하고, `guest:<UUID>` 및 기존 클라이언트의 유효한 원시 UUID를 지원한다. 영 UUID·잘못된 guest UUID는 거부한다. 외부 키는 `game:member:guest:<UUID>`로 분리하고 재전송 시 같은 회원 UUID를 사용한다. 진단된 기존 별칭 1건은 비공개 매핑 설정에서 게스트로 교정했다.
3. 관측소의 실행 예정 시각 초과 시간을 전체 대기 시간으로 오해할 수 있었다. queued_at 기준 최대 대기, next_attempt_at 기준 예정 시각 초과, 다음 예약 재시도까지의 시간을 분리했다. 지표 확인 실패는 미확인으로 표시하고 확인된 예약 부재만 ‘예약 없음’으로 표시한다.

- 게이트웨이 외부 접속 키와 내부 collector 키는 역할이 다르다. 외부 복구 요청에는 게이트웨이 키를 사용한다. 원본 journal에는 개인정보가 포함될 수 있으므로 제한된 위치에 보관한다.
