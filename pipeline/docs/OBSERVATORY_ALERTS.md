# 대시보드 알림 센터

2026-11-23 / http://127.0.0.1:8011/

## 사용법

- 화면 팝업은 새 경고·등급 변경·복구 시 자동 표시됩니다. 첫 접속 때 과거 이력을 다시 울리지 않습니다. 한 번의 조회 사이에 발생한 여러 알림도 빠뜨리지 않고 묶어 알립니다.
- **소리 켜기**: 현재 탭에서 소리를 허용합니다. 브라우저 자동 재생 정책에 따라 소리가 제한될 수 있습니다.
- **브라우저 알림 켜기**: 사용자가 직접 버튼을 눌러 권한을 허용해야 합니다. 지원 브라우저의 HTTPS 또는 localhost에서 사용합니다. 일반 HTTP 내부 IP에서는 화면 알림을 이용하세요. 페이지가 닫혀 있으면 동작하지 않습니다.
- **15분 알림 끄기**: 팝업·소리·브라우저 알림만 억제합니다. 서버 관측과 경고 이력은 계속 기록합니다. 만료 뒤 새로 발생하는 알림부터 다시 알리며, 억제 중 알림을 몰아서 울리지 않습니다.
- **모두 확인**: 현재 탭의 미확인 표시만 지웁니다. 장애를 해결·재처리하거나 다른 사용자의 확인 상태를 바꾸지 않습니다.
- **알림 시험**: 운영 데이터나 실제 이력을 변경하지 않는 시험 팝업입니다. 켜 둔 소리·브라우저 채널도 시험하며, 15분 끄기 중에도 시험 버튼은 동작합니다.
- 설정과 확인 상태는 현재 탭에서만 유지합니다. 새로고침하면 기본 설정으로 돌아갑니다. 화면 일시 정지 중에는 클라이언트 알림도 정지하지만 서버 관측은 계속됩니다.

## 경고 기준

| 대상 | 조건 | 확인 횟수 |
|---|---|---|
| Spark 진행 신호 | 진행 파일 없음·읽기 실패 또는 30초 초과 오래됨 | 1회 |
| 로컬/원격 MongoDB, 수집기 | 구성된 대상의 준비·연결 확인 실패 | 1회 |
| 스트리밍 쿼리 | active=false | 1회 |
| 진행 지연 | 대기 데이터 있음 + 최근 완료 배치가 60초 초과 | 연속 2회 |
| 배치 지연 | 입력 있는 최근 배치 5초 초과, 배치 시각 60초 이내 | 연속 3회 |
| 적재 중단/보관 | blocked / parked 건수 있음 | 1회 |
| 처리 가능한 대기 | 가장 오래된 대기 60초 초과 | 연속 3회 |
| 회원·선행 순서 대기 | waiting_context 최고 대기 10분 초과 | 연속 2회 |
| 브라우저→관측 API | 화면 새로고침 요청 연속 3회 실패 | 현재 탭 알림만 |

서버 관측 주기는 기본 10초, 일부 준비 확인은 30초 캐시입니다. 연속 횟수는 독립 장애 횟수가 아닌 관측 횟수입니다. 원인 해소 관측 시 복구 이력을 남깁니다. DB·진행 신호가 불명확할 때 그에 의존하는 경고를 근거 없이 복구 처리하지 않습니다. 같은 경고 반복 관측은 새 알림을 만들지 않으며, 등급 변경이나 해결 후 재발은 새 이력입니다.

## 저장·검증·제한

관측소 전용 MongoDB 컬렉션 `observatory_alert_state`에 활성 경고와 최근 발생·변경·복구 100건을 한 문서로 저장하고 시작 시 복원합니다. 업무 이벤트·회원 문서는 수정하지 않습니다. MongoDB 장애 중에는 메모리에서 계속 관측하며 화면에 이력 저장 실패를 표시합니다. 이 상태에서 관측소까지 재시작하면 미저장 이력이 유실될 수 있습니다. 복수 관측소 프로세스의 상태 공유·동시 쓰기는 지원하지 않으므로 한 인스턴스로 운영합니다.

검증: Python 106 passed / PySpark 의존 1 skipped. Node 검사로 과거 이력 무음, 중복 억제, 동시 경고, 확인, 연결 복구, 알림 끄기와 시험 예외를 확인했습니다. 실제 브라우저에서 미확인 확인 처리·알림 끄기/다시 켜기·시험 팝업과 콘솔 오류 없음도 확인했습니다. OS 알림 권한 부여와 실제 스피커 출력은 사용자 환경에서 확인해야 하며 자동 검사 통과로 대신하지 않습니다.

현재 알림은 열려 있는 대시보드용입니다. MySQL 별도 연결 확인, 게임부터 화면까지의 종단 SLA, 외부 Slack·메일·문자 발송은 포함하지 않습니다. 향후 상시 서버 알림 단계에서 수신자·발송 경로·재알림 간격을 정해 연동합니다. 운영 TTL은 168시간 그대로 유지했습니다.
