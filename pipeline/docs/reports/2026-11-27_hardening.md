## 3. 원격 DB 유실 감지·복구 절차

- stored 이력을 새 이벤트 유무와 관계없이 주기적으로 대조한다. 매 30초 순회 100건과 최신 10건을 검사하며 원격 아카이브·세션·문제·시도·이벤트·MySQL 회원을 확인한다. 조회는 컬렉션별 묶음 처리로 제한했다.
- 유실·불일치면 적재를 보호 중지하고 관측소에 경고한다. 중지 상태는 재시작해도 유지되며, 전체 검증 및 현재 incident를 명시한 해제만 허용한다. 접속 실패는 자료 유실과 구분한다.
- 별도 실제 MongoDB 시험 DB 10건으로 자료 유실 감지·중지 유지·복원 후 검증 해제를 확인했다. 운영 DB 삭제는 하지 않았다. 운영 보존 stored **6,366건** 전체를 실제 원격 MySQL·MongoDB와 대조해 통과했다.
