{% include 'accounts/nav_icon.html' with icon='message' %}자주 묻는 질문

힌트 기록이 없으면 미사용인가요?

아닙니다. 이벤트가 없다는 사실만으로 힌트 미사용이나 실패 없음으로 단정하지 않습니다. 해당 게임이 힌트 이벤트를 보내는지 먼저 확인하세요.

평균 풀이 시간이 비어 있는 이유는?

해결한 문제가 없으면 ‘기록 없음’, 해결 기록은 있지만 풀이 시간(active_ms)이 저장되지 않았으면 ‘미수집’으로 표시합니다. 누락된 시간을 0초로 채우지 않습니다.

포기는 왜 ‘집계 전’인가요?

지금 게임과 파이프라인은 포기 이벤트를 보내지 않습니다. 그래서 시작했지만 해결 기록이 없는 문제는 모두 ‘미완료’로 셉니다.

분류되지 않은 기록은 어디에 들어가나요?

문제 ID가 24종 실행 ID와 맞지 않으면 전체 지표에는 포함하고, 특정 게임이나 분야에는 임의로 넣지 않습니다. 게임 분석 화면 아래에 따로 표시합니다.
