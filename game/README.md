# game/ (자리만 잡아 둠)

Godot 게임 코드는 현재 원본 저장소에서 업데이트 중이라 아직 가져오지 않았습니다.

- 원본: https://github.com/junbum8398-blip/nodeverse-game (`main`)
- 가져오는 방법: [`docs/BRANCH_STRATEGY.md`](../docs/BRANCH_STRATEGY.md)의 "game/ 가져오기" 절차를 따릅니다.
  히스토리를 유지한 채 `game/` 아래로 옮기고, Godot 바이너리 에셋은 Git LFS로 저장됩니다.

> ⚠️ 원본 저장소 히스토리의 `website/config.js`에 Groq API 키가 남아 있습니다 (2026-11-09 ~ 11-16 커밋).
> 가져올 때 히스토리에서 지우는 절차가 문서에 포함되어 있으며, 키 자체는 Groq 콘솔에서 폐기해야 합니다.

이 README는 게임 코드를 가져오면서 삭제합니다.
